Hice un conjunto de funcionalidades relacionas con la creación-recorte-renombramiento-reubicación de tandas de imágnes, con la finalidad de incrementar la calidad final de la base de datos de la forma más automatizada posible, para lograr esto, diferentes metodos han sido aplicados, como el borrado de fotografías desenfocadas, borrado de fotos que contienen determinados objetos, borrado de imágenes cuya resolución no es divisible por dos, etc...

Analizador de latencia con Windows forms.

Desarroyé una simple y rápida aplicación para windows que sondea (ping) un sitio web dado cada pocos milisegundos para comprobar el tiempo de respuesta, después esta información es guardada y procesada para hacer deducciones de si la calidad de la red es apta para cosas que requieren estabiliad, como jugar online o realizar videollamadas, es útil para comprobar si otros usuarios de una red compartida están usándola de una manera en la que pueda interrumpirte, sin invadir la privacidad de ellos.

Windows forms + selenium webscrapper for in real-time wind energy generation

Un webscrapper basado en Windows Forms + selenium para consultar la generación a nivel nacional de energía eólica en tiempo real.

Me he dado cuenta de que la gente se preocupa demasiado por los precios de la electricidad en el momento actual pero no tienen una estrategia a largo plazo para tumbar tanto los precios de la electricidad como las emisiones que esta genera, asi que desarroye un webscrapper para sacar información el tiempo real del porcentaje de cuanta energía eólica se vierte en la red eléctrica de Irlanda, el plan era usar esta información junto a la de predicciones meteorológicas para programar el uso de electrodomésticos en un periodo de tiempo óptmio, pero no encontré una manera de comercializar esto o encontrar personas interesadas en ello, así que termino siendo una herramienta de uso peronal. Aunque aún estoy interesado en finalizarla si se da el caso.
